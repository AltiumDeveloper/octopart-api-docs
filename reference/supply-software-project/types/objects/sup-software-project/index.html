SupSoftwareProject

No description

Common Data Model​

  • Software Project — A software project published in the supply catalog, together with the evaluation kits it is compatible with. In Renesas 365 it can be imported into a solution with a compatible eval kit; the import places the project in the Workspace and links it to the solution (see sft_SoftwareProject).
    • IRI: https://w3id.org/altium/cdm/supply/SoftwareProject
    • GRID: grid:supply::platform:software-project/{id}
