# Common — types
> Types of the Common bounded context that are not entities, one line each; Relay `*Connection` and `*Edge` types are omitted. Entities, entry points and operations: [llms.txt](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/llms.txt).

- [PageInfo](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/objects/page-info.md): Information about pagination in a connection.
- [Error](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/interfaces/error.md)
- [SortEnumType](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/enums/sort-enum-type.md)
- [Boolean](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/scalars/boolean.md): The `Boolean` scalar type represents `true` or `false`.
- [DateTime](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/scalars/date-time.md): The `DateTime` scalar represents an ISO-8601 compliant date time type.
- [Float](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/scalars/float.md): The `Float` scalar type represents signed double-precision fractional values as specified by [IEEE 754](https://en.wikipedia.org/wiki/IEEE_floating_point).
- [ID](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/scalars/id.md): The `ID` scalar type represents a unique identifier, often used to refetch an object or as key for a cache.
- [Int](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/scalars/int.md): The `Int` scalar type represents non-fractional signed whole numeric values.
- [Long](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/scalars/long.md): The `Long` scalar type represents non-fractional signed whole 64-bit numeric values.
- [Map](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/scalars/map.md)
- [String](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/scalars/string.md): The `String` scalar type represents textual data, represented as UTF-8 character sequences.
- [deprecated](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/directives/deprecated.md): Marks an element of a GraphQL schema as no longer supported.
- [include](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/operations/directives/include.md): Directs the executor to include this field or fragment only when the `if` argument is true.
- [oneOf](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/directives/one-of.md): Indicates exactly one field must be supplied and this field must not be `null`.
- [skip](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/operations/directives/skip.md): Directs the executor to skip this field or fragment when the `if` argument is true.
- [specifiedBy](https://altiumdeveloper.github.io/octopart-api-docs/reference/common/types/directives/specified-by.md): Exposes a URL that specifies the behavior of this scalar.
